# Lee & Yang (2017) — Sistema inteligente de monitorización con smart plugs distribuidos

- **Tipo:** artículo de revista, revisado por pares. *International Journal of Distributed Sensor Networks*, 13(7).
- **PDF local:** sin PDF local. Open access (GOLD): https://doi.org/10.1177/1550147717718462 — ficha basada en el abstract online (pendiente de lectura completa).
- **Referencia (borrador):** Lee, S.-H.; Yang, C.-S. (2017). An intelligent power monitoring and analysis system for distributed smart plugs sensor networks. *International Journal of Distributed Sensor Networks*, 13(7), 1550147717718462. https://doi.org/10.1177/1550147717718462

## Qué aporta
- Framework de gestión energética en tres partes: **smart plug** (mide tensión/corriente, conmuta la carga y admite sensores según el entorno), **gateway inteligente** (fog computing con modelo de inferencia local por deep learning) y **plataforma + app móvil** (visualización y control remoto).
- Referencia de arquitectura por capas (medida → edge → visualización) similar a la nuestra.

## Datos clave
- El gateway aplica fog computing: el modelo se entrena, actualiza y mejora localmente para control inteligente.
- Viabilidad demostrada experimentalmente en red de sensores distribuida.

## Dónde usarlo

- **Cap. 3 (definición del sistema):** referencia de arquitectura por capas.
