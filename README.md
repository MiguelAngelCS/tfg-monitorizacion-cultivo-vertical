# Monitorización energética de una planta piloto de cultivo vertical

Trabajo de Fin de Grado — Grado en Ingeniería en Tecnologías Industriales
Escuela Superior de Ingeniería, Universidad de Cádiz

**Alumno:** Miguel Ángel Castillo Sánchez
**Tutor:** Salvador Canas Moreno (UCA, TEP-940 Robótica Aplicada)

## Resumen del proyecto

Diseño e implementación de un sistema de bajo coste para la monitorización de consumos
eléctricos de una planta piloto de cultivo vertical, mediante sensores en las tomas de
corriente, un datalogger basado en Raspberry Pi y software de desarrollo propio en código
abierto (recogida → almacenamiento → visualización). El objetivo es estudiar el consumo
de la planta para valorar la viabilidad de proyectos de este tipo.
